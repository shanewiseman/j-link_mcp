# Protocol bridge extension

The universal protocol bridge is not part of the target-neutral core. It is an
optional separately installed extension with ID `giga_protocol_bridge`, and it
requires the `arduino_giga` extension.

Firmware, wire protocol, release checks, deployment workflow, tools, pinned
libraries, physical-fixture requirements, SBOM, and licensing are maintained in
the [canonical bridge documentation](../extensions/giga_protocol_bridge/docs/protocol-bridge.md).
